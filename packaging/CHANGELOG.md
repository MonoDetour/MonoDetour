# Changelog

MonoDetour's changelogs can be found in GitHub releases: <https://github.com/MonoDetour/MonoDetour/releases>

## Thunderstore Specific Versions

MonoDetour adds a padding version for Thunderstore releases to allow uploading MonoDetour packages to new Thunderstore communities without desyncing the version between Thunderstore releases and other releases like NuGet. The Thunderstore version is calculated from the MonoDetour version like so: `major.minor.(patch * 100 + thunderstore-sub-version)`.

This Thunderstore specific changelog lists Thunderstore communities MonoDetour has been added to. Also note that this changelog is shared for all MonoDetour packages.
